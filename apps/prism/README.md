# Prism

A gallery of the SAGE Incident Lens design system: color, typography and motion tokens, plus live component variants with copyable usage snippets — extracted from `apps/sage-incident-lens-web` (`tailwind.config.ts`, `src/app/globals.css`, `src/app/page.tsx`).

## Develop

```bash
npm install
npm run dev
```

## Build & serve

```bash
npm run build
npm run preview   # serves dist/ statically
```
