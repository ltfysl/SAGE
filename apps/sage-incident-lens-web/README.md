# SAGE Incident Lens — Web Dashboard

A polished, premium developer dashboard for AI-powered log analysis and incident investigation.

## Setup

```bash
cd apps/sage-incident-lens-web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- **Upload & Analyze**: Drag-and-drop log files for instant AI analysis
- **Interactive Dashboard**: Severity summaries, event categories, exception rankings, timelines, evidence highlights
- **Ask SAGE**: Natural language Q&A about your incident logs
- **Export**: Download analysis as Markdown

## Privacy

All analysis runs **locally on your machine**. Log files are never uploaded to any external service. The SAGE engine processes everything within your environment.
